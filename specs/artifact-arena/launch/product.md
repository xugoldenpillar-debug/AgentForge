# 产品与题目规则

> 首发范围调整：以 [BYOK 首发方案](byok-first.md) 为准；以下平台模型首发和美元上限要求由该调整覆盖，安全/资源限制与工程验收仍须完成。

## P1. 两道固定原题

题面 instructions 按下列原文存储，不补造额外隐藏要求；解释、输出和安全限制显示在独立“运行规则”区域并版本化。

| 顺序 | 稳定 ID / slug | 标题 | 原题 |
| --- | --- | --- | --- |
| 1 | `pelican-bike` | 鹈鹕骑自行车 | 创建一个HTML，内容是SVG绘制一个鹈鹕骑自行车的2D动画。 |
| 2 | `qin-polar-bear` | 秦始皇骑北极熊 | 生成HtmL，内容是svg绘制秦始皇骑北极熊的动画 |

首版本均为 v1，使用 `svg-animation-v1` 输出规则。目录顺序固定，旧 Workflow 题目保留在独立分类，不删除旧数据或改变其评分。稳定题目 ID、不可变版本 ID 与内部数据库主键分开；初始化幂等，内容变化必须新版本，不能覆盖已运行版本。

“不用进行测试”的产品解释：第二题（首题也同样）不设自动答案判题或隐藏测试，不要求创作者提交测试代码；不取消工程回归、真实运行、动画预览、安全和发布验收。没有隐藏 suite，不用空 suite 或 contains 判题冒充通过。

## P2. 交付物与动画

- 必交 `index.html`，包含内联 SVG；README.md 为可选说明，不因缺 README 判不合格（替代旧样板的双必交要求）。
- 可选本 bundle 的 CSS、SVG、PNG/JPEG/WebP、MD；原件保持不变，安全预览为有版本的派生件。
- SVG 承担主体绘制，不接受只有截图/emoji 的占位演示。是否确实像题目主体、动作是否合理由社区评价，不用标签名或关键词自动宣称语义合格。
- 动画限 CSS keyframes、受限 SVG animate/animateTransform。不要求 JS、网络、npm、shell 或 Python。
- 预览提供播放/暂停/重新开始；暂停可以切换静态派生图并销毁动画 iframe，重新开始重建隔离 iframe，不为控制引入作品脚本。页面失焦/作品离屏卸载预览；尊重减少动态效果偏好，默认静态并允许主动播放。
- 初始技术限制：最多 16 文件、单文件 2 MiB、bundle 8 MiB；HTML/SVG 解析深度 64、节点 20,000、动画元素 200；不合规有可读原因、可看源码，不静默显示空白或冒称合格。实际性能测试可收紧限制，但需新政策版本与兼容说明。

## P3. 用户与运行

- 全部正常注册、未封禁、满足现有身份策略且有配额的用户可用，无需 Pi 邀请/申请。保留账号认证和资源所有权；旧 PoC 自测接口不通过删除其 gate 来复用。
- 首版支持平台批准模型；若开放 BYOK，则沿用凭据加密、owner 校验、允许域/SSRF 与预算规则，并在独立 trust lane 展示；BYOK 未就绪不影响平台路径交付。
- Skill 只接现有组件库的声明式固定版本，检查许可、归属和撤销；不执行 Skill 包内脚本或安装依赖。可以不选 Skill 完成运行。
- 显示模型、预算、是否可能收费并取得运行同意。每用户最多 1 个活跃 run、3 个排队 run、10 次新建 run/滚动24小时；默认每 run 120 秒、16,000 tokens、40 次工具调用、费用上限 USD 0.10。供应商价格缺失/预算不足拒绝新任务，不编造实际费用。
- 上述数值为待压测的发布候选，不是容量证明或支出授权。全站日预算与并发上限必须由发布负责人结合供应商额度明确设置，缺失拒绝开放。配额在共享持久层原子实施，不能仅在浏览器计数。
- 刷新恢复状态，重复点击不重复扣费；取消须确认模型与沙箱停止；失联或付费结果不确定进入核查，不自动重跑付费调用。

## P4. 发布、点赞、评分和排名

- run 成功后默认私有；仅 owner 在安全预览成功后明确确认发布，完成作品不经过人工审核并立即公开。作品公开不等于 Prompt、Skill、凭据或构建公开。
- 新作品不创建 pending 审核记录；保留 withdrawn/taken-down、举报、管理员撤下与审计。只有用户提交的新题目/议题进入审核队列。
- 一个用户在同一题目版本/赛季/trust lane 仅一个活跃参赛 entry；新作品由 owner 发布后可原子替换，旧 release 历史保留，新 entry 从零计票，不继承点赞/分数。公开作品可不参赛。
- 点赞：登录、非作者、每用户每 release 一票；PUT/DELETE 幂等，支持取消；不影响社区分、用户 rating 或 Verified。公开作者的点赞不能作为盲选票复用。
- 社区分沿用 `showcase-pairwise-v1`：同 comparator 的服务端配对、随机 A/B，胜=1，平=0.5，跳过不计；社区分=100×得分/有效对决数，展示样本数和政策版本。投票前隐藏作者/模型/热度；作品内署名无法保证去识别，不能宣传严格双盲。
- 正式榜门槛：每 entry ≥20 有效票且 ≥10 独立选民；否则显示“样本不足/待排名”，不显示伪造 0 分。按社区分、有效票数、entryId 稳定排序。
- comparator 冻结题目版本、赛季、输出/投票政策、预算档、环境兼容组、Pi 版本策略、trust lane。跨题、跨信任等级不混榜；当前无 Verified 证据的模型不得显示 Verified。
- 另有“最多点赞”“最新”排序，明确不是正式得分榜。费用/token/执行时长为效率信息，不合成艺术总分；排队时间独立显示。
- 防刷：禁投己方作品，沿用 pair 唯一票、ballot 10 分钟过期、每小时60次 ballot/30张有效票；点赞写请求每用户60次/小时。数据库唯一约束与共享限流一起生效。异常票隔离、记录原因、重算 revision/asOf，不静默删除审计。
- 撤下作品即拒绝新预览/点赞/投票并退出当前榜；历史票保留用于审计，缓存失效，已下载字节不可收回。

## P5. 页面

首页首发专区、动画题列表/详情、带真实题目参数的 Agent Builder、运行详情/事件、作品文件树与动画预览、发布确认/撤下反馈、作品详情/点赞/举报、盲选页、分题榜单、个人作品、最小审核后台。

桌面与窄屏都覆盖加载、无作品、样本不足、配额耗尽、依赖不可用、运行失败、取消中、发布前私有、撤下。无后端能力时按钮说明原因；禁止 fixture 替代真实结果。
