## 与上一阶段的区别

1. 首批正式题目固定为鹈鹕和秦始皇两道 SVG 动画题，不是通用静态占位作品。
2. 无脚本不等于无动画：支持受限 CSS keyframes 和 SVG 声明式动画；不开放任意 JavaScript。
3. 两题均不设标准答案或隐藏测试集；自动检查只给技术合规状态，社区盲选给社区分，点赞单独统计。
4. 目标受众是全部正常注册用户，不是 Pi 申请/邀请名单；匿名访客可以看公开作品和榜单，不可运行、点赞或投票。
5. 两题复用 versioned CreationRun 和 EF creation 执行链，带可空的固定挑战关联。为防止另造临时执行器，creation v2 是本次必交基础，不要求同时交付自由问题 UI。
6. 固定环境、真实执行、持久作品、社区机制和公开入口均为必交；可组合环境高级画布、自由题目 UI、Python 轨、hidden Agent judge、多 Agent、可执行 Skill 和 JS 档位后置，不阻塞这两题发布。

原始规格编写轮次仅改文档；当前已进入实现轮次，进度见 [实现状态与发布阻塞](implementation-status.md)。当前仍不打开运行开关、不写生产题目、不调用付费模型、不部署或更改线上权限。后续实施以全用户开放为目标，但采购、预算、生产目标与安全验收必须有明确记录；不得把“所有用户”解释成匿名无限免费调用。
