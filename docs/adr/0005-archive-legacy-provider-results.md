# Archive legacy provider results

Submissions created before AgentForge records Benchmark Profiles, Seasons, Evaluation Suite versions and gateway provenance will remain visible only as Legacy Submissions and will not be inferred into the new leaderboards. Existing credentials whose normalized endpoint exactly matches DeepSeek's approved official endpoint may be migrated into the Official Provider Registry; other credentials become disabled legacy custom endpoints unless their owner has developer or administrator access.

## Consequences

No historical result is silently upgraded to Verified status, and no encrypted credential is deleted or exposed during migration. New leaderboards start with complete provenance, while legacy Build history remains available for users who need to inspect past work.
